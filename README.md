# Broken Genesis

Retro-inspired 2D fighting game prototype: Kira vs. Volt on a neon rooftop stage.

The current build uses the Broken Genesis cast: Bryan, Jonneil, Ranelle, Yokan, Dice, Roj, Hope, Miguel, Bennedic, Fallan, and Lynne. It includes fighter selection, CPU opponents, three procedural music tracks, hit/jump sound cues, and switchable realistic Lambda battle backgrounds.

## Run with Docker

```bash
docker compose up --build
```

Open http://localhost:8080.

## Controls

- Player 1: `WASD` to move/jump, `J` light attack, `K` heavy attack
- Player 2: arrow keys to move/jump, `1` light attack, `2` heavy attack
- Touch controls appear on small screens.
- On the select screen, choose the P1/P2 slot, pick a fighter, then choose `VS COMPUTER` or `2 PLAYERS`.
